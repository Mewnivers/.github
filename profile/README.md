# Mewnivers

Mewnivers regroupe des projets open source pour les communautés en ligne : bots et outils.

## Projets

| Projet | Description | Technologies |
|---|---|---|
| [Motisma](https://github.com/Mewnivers/Motisma) | Bot Discord pour communautés Pokémon GO : sorties, classement, niveaux et mini-jeux. | Node.js, discord.js, PostgreSQL, Docker |

## Contribuer

- Une idée, une question ou un bug : ouvrez une [Issue](https://github.com/Mewnivers/Motisma/issues) sur le dépôt concerné.
- Avant de proposer du code, lisez le [CONTRIBUTING.md](https://github.com/Mewnivers/Motisma/blob/main/CONTRIBUTING.md) du dépôt.
- Une faille de sécurité : ne la publiez pas, signalez-la en privé via les [Security advisories](https://github.com/Mewnivers/Motisma/security) du dépôt.
