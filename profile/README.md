# Mewnivers

Mewnivers regroupe les outils de la communauté Pokémon GO de Pau : un bot Discord et un site web.

Rejoindre la communauté : [discord.gg/XwZ4sPaf9A](https://discord.gg/XwZ4sPaf9A)

## Projets

| Projet | Description | Technologies |
|---|---|---|
| [Motisma](https://github.com/Mewnivers/Motisma) | Bot Discord de la communauté : accueil et vérification des nouveaux, sorties avec `/rdv`, niveaux et classement Pokémon GO, mini-jeux, sondages, menus « Déplacer » et « Traduire » (FR, EN, ES). Open source. | Node.js, discord.js, PostgreSQL, Docker |
| [Site POGO PAU](https://pogo-pau.mxrine-mz.dev/) | Site et API de la communauté, avec la page d'invitation au Discord. Code privé. | React, Vite |
